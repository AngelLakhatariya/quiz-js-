🎯 GK QUIZ CHALLENGE 🧠⏱️

~Test your general knowledge under a 20-minute countdown timer!

## 🔹 Project Description
GK Quiz Challenge is an interactive web application built using "HTML, CSS, and JavaScript".  
It features **10 General Knowledge questions** accompanied by an active "20-minute countdown timer".

Users can answer the questions and submit manually via the "Submit button", or the quiz will "automatically submit" when the timer runs out. Once submitted, the application 
calculates the total score, displays the final result, and disables all radio inputs to prevent further changes.

----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## 🔹 Key Features
- 10 Multiple-Choice Questions (MCQs)
- 20-minute real-time countdown timer
- Auto-submission on timer expiration
- Instant score calculation logic
- Post-submission input locking (Anti-cheat)
- Clean, modern dark-mode responsive UI

----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## 🔹 How This Project is Built
- **HTML5**: Used for structuring the quiz container, form controls, and individual question sets.
- **CSS3**: Applied for custom dark-mode aesthetics, smooth button transitions, hover states, and dynamic display handling.
- **JavaScript**:
  - Implemented `setTimeout()` to drive the 20-minute recursive countdown clock.
  - Used `getElementsByClassName()` to detect elements marked with the correct answer class.
  - Used DOM iteration to verify selected radio buttons against the correct answers and tally the user's score.
  - Dynamically disabled all input fields and updated the UI elements upon form submission.
